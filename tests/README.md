# Tests

Unit test helper murni (tanpa database), dijalankan dengan Node bawaan:

```
cd frontend
npm test
```

- `wa.test.mjs` — normalisasi nomor WhatsApp & link wa.me
- `validate.test.mjs` — helper validasi server action

Pengujian modul lengkap (login, scan, foto, WhatsApp) dilakukan manual di HP sesuai README bagian 10.
